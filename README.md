# PS3 - Address geocoder that learns from field visits (Tasks 1-5)

Every address gets a **pin**, a **calibrated confidence radius**, a **confidence tier with a suggested action**, and **offline landmark directions**. Each confirmed field visit becomes new evidence that improves its neighbours. All figures below are regenerated by one command from the raw CSVs and checked by tests.

```bash
pip install -r requirements.txt
python run_pipeline.py            # everything, ~5 min   (add --fast to skip slow optional steps, --retune to refit sigmas)
open demo_map.html                # offline interactive demo (double-click)
```

## Headline results (synthetic data; see `SUMMARY.md`, `results/summary_metrics.json`)

| 100 surveyed addresses, out-of-fold | old geocoder | ours |
|---|---:|---:|
| Median / 90th-percentile error | 376 / 839 m | **46 / 369 m** |
| Within 50 / 100 / 250 m | 5% / 9% / 35% | **51% / 65% / 86%** |
| Visited addresses (49), median | 384 m | **11 m** |
| Unvisited addresses (51), median / P90 | 363 / 653 m | **132 / 535 m** |

* **No-visit addresses, large sample** (1,231 visited addresses with their own visits hidden): median **321 -> 126 m**, within 100 m **12% -> 42%**.
* **Confidence is honest:** the 90% radius contains the true location **91%** of the time (95% CI 84-95%, calibrated on data the model never saw); tiers separate easy from hard (high tier: 97% within 100 m; low tier: 20%).
* **It learns:** with no visits the median is 239 m; with 862 visited addresses known it is 136 m, and still falling (`results/learning_curve.png`).
* **Field impact (indicative, observational):** -17% not-traceable rate, -11% minutes per visit, +10% productive visits per agent-day if pins on unvisited addresses move from old to new error (`results/impact_estimate.csv`; the pilot plan tests it properly).

## Tests (run automatically by the pipeline)

* `test_task3.py` - no leakage (a fold's predictions ignore its own truth; development ignores the official-test truth), online update moves neighbours, tight visit clusters are protected, output contract.
* `test_task4.py` - radii ordered, 90% radius calibrated on held-out surveyed addresses, tiers rank accuracy, 597/598 sampled direction clauses reproduce landmark distance and compass bearing, PS2 and offline packs valid.
* `verify_package.py` - Task 1-2 invariants and notebooks execute.

## Honest limits

* Synthetic data; real-world accuracy is unproven until the pilot.
* Pincode-level addresses with no locality in the text cannot be resolved from text (median ~1.3 km, same as the old pin); they are flagged low confidence and routed to verify-first. They set the 90th percentile.
* 100 survey labels is small: strata under ~10 addresses are anecdotes. Survey truth covers residences only.
* The official-test fold was seen during early exploration; a clean blind claim needs fresh survey data.
* x east / y north orientation and the Hinglish / Kanglish direction phrases are assumptions to confirm with CN.
